# Классификация изображений на CIFAR-10 с помощью SimpleResNet

## О проекте

Этот проект представляет собой решение задачи многоклассовой классификации изображений из датасета **CIFAR-10**. В качестве архитектуры нейронной сети используется упрощенная версия **ResNet**, реализованная на **PyTorch**.

Основной код, визуализации и выводы представлены в Jupyter Notebook `hw1_notebook.ipynb`.

## Ключевые особенности

*   **Архитектура:** Реализована CNN-архитектура, подобная ResNet-18, с использованием остаточных связей (residual connections) для эффективного обучения глубокой сети.
*   **Воспроизводимость:** Установлены `random seed` для всех библиотек (`torch`, `numpy`, `random`), чтобы обеспечить полную воспроизводимость результатов.
*   **Аугментация данных:** Применяются техники аугментации ( `RandomHorizontalFlip`, `RandomCrop`) для тренировочного набора, чтобы улучшить обобщающую способность модели и бороться с переобучением.
*   **Ранняя остановка (Early Stopping):** Реализован механизм для прекращения обучения, если качество модели на валидационной выборке перестает улучшаться, что экономит время и предотвращает переобучение.
*   **Логирование:** Используется **TensorBoard** для визуализации процесса обучения (графики потерь и точности).

## Используемые технологии

*   **Python 3.8+**

## Как запустить

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL_вашего_репозитория>
    cd <название_папки>
    ```

2.  **Установите зависимости:**
    ```bash
    pip install torch torchvision numpy matplotlib seaborn scikit-learn tensorboard jupyterlab
    ```

3.  **Запустите Jupyter Notebook:**
    ```bash
    jupyter lab
    ```
    В открывшемся интерфейсе откройте файл `hw1_notebook.ipynb` и выполните ячейки последовательно.

4.  **(Опционально) Мониторинг через TensorBoard:**
    Для просмотра графиков обучения в реальном времени или после выполнения, откройте новый терминал и выполните:
    ```bash
    tensorboard --logdir=runs
    ```

## Результаты

Модель была обучена в течение нескольких эпох и оценена на тестовом наборе данных. Лучшая модель (с минимальным `loss` на валидационной выборке) была сохранена и использована для финальной оценки.

### Отчет о классификации

```

   automobile       0.94      0.91      0.92
```

### Выводы по результатам

*   **Сильные стороны:** Модель отлично справляется с распознаванием **техники** (`automobile`, `ship`, `truck`), где F1-score достигает **0.90-0.92**.
*   **Слабые стороны:** Основные трудности возникают при различении похожих **животных**. Самые низкие показатели у классов `cat` (F1: 0.65) и `dog` (F1: 0.70), что указывает на то, что модель часто путает их между собой.
*   **Дальнейшие улучшения:** Для повышения качества можно попробовать более сложные аугментации, подобрать гиперпараметры или использовать предобученную на ImageNet модель (transfer learning).
