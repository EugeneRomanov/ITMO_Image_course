# HW3: Self-Supervised Learning (на базе HW1)

## Описание задачи

В данном домашнем задании решается задача **self-supervised предобучения** на датасете CIFAR-10 с использованием техники *Context Prediction*.

Основная цель — продемонстрировать, как предобучение на неразмеченных данных может улучшить качество модели классификации, особенно в условиях дефицита размеченных примеров.

Эксперимент состоит из двух ключевых этапов:
1.  **Предобучение Feature Extractor'а:** Архитектура на базе ResNet18 обучается на вспомогательной задаче — предсказании взаимного расположения двух патчей одного и того же изображения. Этот этап использует обучающую выборку CIFAR-10 **без меток**.
2.  **Обучение классификатора:** Предобученный и "замороженный" feature extractor используется в качестве основы для нового классификатора. Его эффективность сравнивается с baseline-моделью (обученной с нуля) на малом количестве размеченных данных: **N=100, 50 и 10** примеров на класс.

## Датасет

Используется стандартный датасет **CIFAR-10**.
- **Для self-supervised этапа** используется обучающая выборка (45 000 изображений) без использования меток классов.
- **Для этапа классификации** формируются урезанные обучающие выборки размером N=100, N=50 и N=10 изображений. Валидация и тестирование проводятся на стандартных наборах данных CIFAR-10.

## Результаты экспериментов

### 1. Self-Supervised предобучение (Context Prediction)

Модель успешно обучалась предсказывать относительное положение патчей, достигнув точности около 45% на валидации. Это значительно лучше случайного угадывания (1/8 = 12.5%) и свидетельствует о том, что модель научилась извлекать полезные визуальные признаки (текстуры, края, формы).

### 2. Сравнение классификации на малых данных

Итоговые метрики точности (accuracy) на тестовой выборке CIFAR-10.

| Размер выборки (N) | Baseline (с нуля) | Self-Supervised (frozen) | Абсолютный прирост |
|:----------------------|:------------------:|:----------------------------:|:----------------------:|
| **100** | 22.97% | 22.84% | **-0.13%** |
| **50** | 17.50% | 22.39% | **+4.89%** |
| **10** | 10.46% | 14.76% | **+4.30%** |

## Выводы

Эксперименты наглядно демонстрируют ключевое преимущество Self-Supervised Learning (SSL): **чем меньше размеченных данных, тем больше пользы от предобучения.**

1.  **При N=100** изображений на класс, пользы от SSL практически нет. Baseline-модель имеет достаточно данных, чтобы самостоятельно выучить релевантные признаки.

2.  **При N=50** преимущество SSL становится очевидным (**+4.89%**). Baseline-модель начинает сильно переобучаться (Train Acc ~98%, Val Acc ~17%), в то время как модель с предобученными признаками показывает гораздо лучшую обобщающую способность.

3.  **При N=10** эффект наиболее драматичен. Baseline-модель показывает результат на уровне случайного угадывания (**10.46%**), что говорит о полном провале обучения. В то же время SSL-модель достигает **14.76%**, что значительно лучше случайного guessing'а и доказывает, что предобученные признаки несут полезную информацию даже для такой сложной задачи.

Таким образом, предобучение без учителя является мощной техникой для построения моделей в условиях дефицита размеченных данных, позволяя значительно повысить качество и стабильность обучения.
