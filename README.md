# HW4: Исследование методов дистилляции знаний на CIFAR-10

## Описание проекта
В данном проекте исследуются и сравниваются различные методы дистилляции знаний (*knowledge distillation*). Цель — передать "знания" от большой, производительной модели-учителя (*Teacher*) к более легковесной и быстрой модели-студенту (*Student*), улучшив ее качество по сравнению с обучением с нуля (*baseline*).

Эксперименты проводятся на датасете CIFAR-10 и включают:
- Классическую дистилляцию логитов.
- Дистилляцию скрытых состояний (feature maps).
- Дистилляцию с помощью обучаемого регрессора.
- Комбинированный метод, объединяющий несколько подходов.

## Архитектуры моделей

### Teacher Network (Учитель)
Более глубокая и широкая сверточная сеть, способная достичь высокой точности.
```
- Conv(3->64) -> ReLU -> Conv(64->64) -> ReLU -> MaxPool
- Conv(64->128) -> ReLU -> Conv(128->128) -> ReLU -> MaxPool
- Linear(128*8*8 -> 256) -> ReLU
- Linear(256 -> 10)
```

### Student Network (Студент)
Более компактная и быстрая сеть с меньшим числом параметров.
```
- Conv(3->32) -> ReLU -> MaxPool
- Conv(32->64) -> ReLU -> MaxPool
- Linear(64*8*8 -> 128) -> ReLU
- Linear(128 -> 10)
```

## Результаты экспериментов

Все модели обучались 30 эпох с использованием SGD и планировщика `MultiStepLR`. Ниже представлена сводная таблица лучших показателей точности на валидационной выборке.

## Анализ и выводы

1.  **Эффективность дистилляции подтверждена.** Все исследованные методы позволили улучшить качество модели-студента по сравнению с baseline-обучением. Это доказывает, что "темные знания" (*dark knowledge*), содержащиеся в выходах учителя, несут полезную информацию для обучения более слабой модели.

2.  **Дистилляция логитов — мощный и простой метод.** Классическая дистилляция через KL-дивергенцию дала самый значительный прирост (**+2.38%**) среди "чистых" методов. Она эффективно передает информацию о взаимосвязях между классами, которую учитель "видит" в данных.

3.  **Комбинированный подход — лучший.** Наилучший результат показал метод, объединяющий дистилляцию логитов (KL-loss) и дистилляцию признаков (MSE-loss). Он достиг точности **80.45%**, сократив разрыв с учителем на **40%** (с 6.59% до 3.93%). Это говорит о том, что передача знаний как на уровне логитов (*что* модель предсказывает), так и на уровне признаков (*как* она к этому приходит) является наиболее эффективной стратегией.

4.  **Дистилляция признаков оказалась менее эффективной в "простых" реализациях.**
    - *Distill Hidden State (Cosine):* Показал минимальный прирост (**+0.12%**). Простое сопоставление "сырых" карт признаков, даже с `Cosine Similarity`, оказалось неэффективным. Вероятно, признаки студента и учителя слишком разнородны для такого прямого сравнения.
    - *Distill with Regressor (MSE):* Использование обучаемого 1x1-сверточного слоя для трансформации признаков учителя дало лучший результат (**+0.62%**), но все равно значительно уступило дистилляции логитов. Это показывает, что даже с адаптацией, заставить карты признаков разных сетей точно совпадать — сложная задача.

**Итоговый вывод:** Для данной пары архитектур наиболее эффективной и простой в реализации является **классическая дистилляция логитов**. Для достижения максимального качества следует использовать **комбинированный подход**, который одновременно передает знания о конечных предсказаниях и о промежуточных представлениях данных.
